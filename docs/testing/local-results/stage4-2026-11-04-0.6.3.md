## Новый тестовый охват

- Strict VLESS-link parsing, отклонение private/metadata IP, unsupported flow/transport, сломанного REALITY public key, повторных параметров.
- Генератор клиента без прямого/freedom обхода, loopback-only socks auth, отказ ложного `pass` при мгновенном выходе Xray, SOCKS handshakes, несекретные ошибки.
- Token hash/TTL (5 минут), старый/дубликат/чужой digest, конкурентные отчёты, приём только applied revision, revoke при drain/deploy/update/removal, протухание через 30 минут и запрет auto publish.
- Admin session и CSRF для grant; анонимный/некорректный bearer не может отправить отчёт; сохранение прежних ревизий после SQLite миграции 0.6.2.
- CLI приватные файлы: open с `O_NOFOLLOW`, world-readable, символическая ссылка, каталог и переполнение запрещены.

**Отсутствие подробностей VM и React здесь — признак `NOT RUN`, а не подразумеваемого успеха.** Никакие реальные секреты не записаны в протокол.
