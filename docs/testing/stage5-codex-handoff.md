## Матрица внешних проверок

- Один VPS: прямой клиентский VLESS/REALITY до интернета, без обязательной второй ноды.
- A→B и B→A: независимый клиент из другой сети, реальный HTTPS через VPN и зафиксированный фактический exit IP (`B` и `A` соответственно).
- A→B при недоступности B: fail-closed; без прямого выхода через A. При наличии C резервируется выход C после N ошибок; восстановление B после M успехов и cooldown. Оценить фактический обрыв текущих TCP сессий.
- Отключить A при доступных B и C: нельзя декларировать работоспособность из-за heartbeat выхода. Client-side переключение входа зависит от конкретного клиента.
- Потеря ACK после успешного apply, потеря TLS controller→agent, перезагрузка каждой VM, остановка Xray, битая конфигурация, устаревший signed bundle, приостановка/удаление ноды. Перезапуск контроллера должен восстановить журнал и корректно компенсировать зависшие транзакции.
- Реальные UDP-протоколы и Happ на поддерживаемых платформах тестируются отдельно. Сервисный TCP ping не является проверкой egress.
