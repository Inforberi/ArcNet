# 0.7.0 stage5: локальные пакеты трафика Xray

2026-11-05. Следующий реализованный вертикальный блок после live monitoring. **Не production, не STAGE4/5_ACCEPTED.**

Добавлены реальные per-user counters локального Xray через private StatsService, транзакционные списания/checkpoints, пакет ГБ, срок и ручной новый период. В UI пользователя — подтверждённый расход/остаток и последние списания; неизвестное не превращается в ноль. Редактор сохраняет draft при CAS-конфликте и не выдаёт pending apply за успешное исполнение. Credentials и subscription ID не меняются.

Добавлены fail-closed политика при stale source/неожиданном restart, повтор применения после ошибки, закрытие экспорта/подписки по политике, восстановление accounting при неудачном удалении пользователя. Контрольное снятие counters до/после управляемого apply отличает его от неожиданной смены процесса; возможный неснятый хвост обозначается как неполный учёт. Backup v6 переносит пакеты/checkpoints/списания и защищает известные суммы от тихого уменьшения при старом restore. Лимит encrypted archive — 64 МиБ; проверен round-trip 65536 debit rows.

Архитектура и ограничения: [ADR-008](adr/008-local-xray-traffic-packages.md). Фактические доказательства: [локальные результаты](testing/local-results/stage5-2026-11-05-user-packages.md).

## Не завершено

- Полный учёт/исполнение Hysteria2, WG, AWG и удалённых нод. Конечный пакет в этой итерации доступен только локальному Xray без зарегистрированных нод/неучитываемых активных движков; прежние безлимитные протоколы не удалены.
- Устройства: отдельные credentials на устройство, лимит выдачи, отзыв, перенос/миграция legacy credential.
- Автоматические календарные периоды/продление; сейчас только явный новый период с CAS и аудитом.
- Независимое создание любого протокола первым; runtime каскадов, Geo, client/server failover, staged multi-node ACK/egress/publish.
- Реальное systemd/VPS quota disconnect и overshoot/нагрузка. Проверенный локальный StatsService не подтверждает REALITY, внешнюю сеть или production блокировку пользователя.
