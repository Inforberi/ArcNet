Настройки → Обновления: рекомендуемый выпуск, история и понятные причины недоступности установки. Пароль администратора — от 8 Unicode-символов.

Что исправлено
Сохранение черновиков, мобильные формы, сообщения об ошибках, подтверждение фактического результата обновления после перезапуска.

Важные изменения
Новые выпуски используют SemVer. Старые сборки доступны в истории без переименования подписанных файлов. Возврат на старую версию не разрешён без проверенного восстановления данных.

Совместимость и ограничения
Core/UI, Linux amd64; без миграции БД, SSH, firewall и systemd units. Для A7–A9 сначала требуется переходный выпуск с поддержкой нового каталога. Реальная VPS-приёмка установки и восстановления остаётся отдельной проверкой.
