# ArcNet: локальный UX-макет для обсуждения

Статус: самостоятельный вариант дизайна, **не утверждён**. Рабочую панель не заменяет. Навигация, формы и данные представлены как демонстрация; нет API-вызовов, действующих ключей, подписок или операций VPS.

## Направление

- Назначение: администратор быстро находит пользователя, читает состояние доступа/расход, открывает управление и выдачу подписки. Режим Impeccable — Operate: предсказуемые элементы, точная плотность и типографика, а не декоративная оригинальность.
- Первая светлая гипотеза отклонена пользователем. Новое требование: только тёмная тема. Текущий кандидат: графитовая основа, сдержанный лавандовый акцент, компактная таблица и отдельная карточка деталей. Светлый переключатель удалён. Дизайн по-прежнему не утверждён.
- Отличительный приём: выбор человека сохраняет список рядом с открытой карточкой. На ширине desktop 1152 список и карточка помещаются рядом. В узком окне карточка следует за списком; выбор пользователя прокручивает к ней и переводит фокус. На 390px меню скрыто бургером, горизонтального переполнения не наблюдалось.
- Не копируем организацию 3x-ui. От неё берём наблюдаемость расхода/лимитов и доступность действий, без ряда неочевидных иконок и огромных форм.

## Сценарии и детали

1. Пользователи: поиск, фильтр, выбор строк, массовое включение/отключение в памяти. Имя открывает карточку; трафик/лимит читаются в одной строке. Расход не заменяет статус активности.
2. Карточка: вкладки Доступ / Трафик / Устройства / Подписка. «Подключить» доступно сразу. Имена устройств задаются человеком; неизвестную модель не выдумывать. График показывает только демонстрационное представление данных.
3. Подписка: отдельное название в приложении, разрешённые подключения, без обязательного выбора клиента. В макете QR и действующая ссылка намеренно не создаются. Переключатели — исследование взаимодействия, не доказательство per-user enforcement.
4. Подключение: отдельный рабочий экран с разделами. Проверка, подбор параметров, сохранение черновика и замена ключей — разные действия. Подбор показывает предложение до внесения в черновик. Расширенные настройки явно раскрываются/скрываются. Ключи — блок данных для чтения, а не псевдоредактируемые поля.
5. Версии ArcNet: видимый пункт навигации, установленная версия и доступные версии. Макет не запрашивает каталог и не устанавливает пакеты.

## Доставка и ограничения

- Локальная страница: `frontend/design-preview.html`; React-композиция — `frontend/src/design-preview/`, существующие React/Tailwind/SVG Icon, без новых зависимостей.
- Запуск из `frontend`: `npm run dev -- --port 5173 --strictPort`, открыть `http://127.0.0.1:5173/design-preview.html`.
- Страница не включена в основной production entry Vite и не связана с маршрутизатором панели. Все значения синтетические и подписаны в UI. Перезагрузка сбрасывает состояние.
- Добавление пользователя — native modal dialog с Escape и браузерным управлением фокусом. Для финальной реализации: guards несохранённых изменений, серверные ревизии, проверки прав и полноценная валидация берутся из рабочего приложения; макет их не заменяет.
- История списаний не возвращается. Каскады, смена ключей, сеть/UFW, серверные операции и существующие рабочие данные не затрагиваются.
