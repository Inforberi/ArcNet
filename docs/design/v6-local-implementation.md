# Перенос v6 — первый локальный блок, 8 ноября 2026

Это начало переноса в **рабочий frontend**, не полная реализация функций демо. Backend пользователей, credentials, VPN и подписок не менялся. Релиза, push и установки на VPS нет.

## Изменения

- `frontend/src/shared/design-system/tokens.css` — семантические темы, цветовые роли, обводки, selected/focus, графики, fluid spacing/type на диапазоне375–1920. Default dark v6; дополнительная тема переопределяет роли, а не компоненты.
- `components.css` — общая реализация nav/buttons/fields/panels/dialogs/tables/status/charts и адаптивного поведения. Старые literal colors общего style.css заменены ссылками на роли; старые light-selector overrides удалены. Полная очистка feature-specific inline/utility colors — дальнейший этап.
- Видимый пункт «Версии ArcNet» и отдельный route, использующий существующий UpdateSettings. Старый переход через настройки сохранён для совместимости.
- «Подключения» в навигации и заголовке. У пользователей сводка только по существующим данным (нет вымышленного online), карточное представление таблицы на мобильном экране.
- Общий dialog сохраняет прежнюю защиту черновика, focus, Escape/backdrop и безопасные mutation API. Сетевые/engine операции не добавлялись.

## Локальный просмотр

Изолированный контейнер `arcnet-v6-ui-review`, localhost18394, временная SQLite и вымышленные identities из существующей opt-in fixture. Пользователь `browser-owner`, пароль `disposable-browser-password-12345` — только тестовая учётная запись. Стенд не подключён к VPS; не проверяет настоящие Xray/WG/systemd. Updater в нём simulated.

Флаг `ARCVPN_UI_REVIEW=1` разрешает существующей browser fixture работать30минут вместо3; default timeout не меняется, обычные тесты fixture пропускают. Go test запускается с `-timeout 35m`. По завершении стенд удаляется вместе с контейнером (`--rm`), timeout не считать функциональным FAIL приложения. Для штатного окончания отправить POST `/fixture-done` локальному стенду. Это test-only endpoint.

Просмотр: `http://127.0.0.1:18394/users`.

## Исправления по скриншотам 8 ноября

- Один border-focus у input/select вместо outline+border, forced-colors оставляет системный focus. У выбранного сервера снята повторная selected-рамка вложенной кнопки.
- Общий chevron select через token темы с отступом14px справа; исправлены интервалы мониторинга/раскрываемых настроек, padding имени пользователя и действие SNI перед мастером SSH.
- Версии показывают числовую часть, полный исходный build доступен отдельно. Несколько одинаковых numeric versions различаются A7/A8 в выборе, underlying values/signature contracts не меняются.
- ConnectionEditor показывает протокол/транспорт/защиту, клиентский fingerprint на первом уровне, дополнительные параметры раскрываются; ключи/Short ID — read-only данные вместо полей. Это не новые transport API.
- По новому прямому требованию ручное создание устройства убрано из UI. Прежние credential записи доступны для подключения/отзыва. Shared key не заменяется автоматически. В unmanaged-профиле явно сказано, что enforcement лимита одновременных IP/устройств ещё не подключён; фиктивного сохраняемого лимита нет. Старый backend/API устройств не удалён, credentials сохранены.
- Полный единый пользовательский редактор v6, назначения, scheduler и concurrent IP/device enforcement не реализованы этим блоком. UI не объявлять полным переносом демо.
- Build/TypeScript, точечные тесты tokens/version identity/device UI — PASS. Local HTTP200. Визуальный browser check повторно заблокирован настройкой Work; screenshot-based acceptance остаётся открытой.

## Полировка по скриншоту 8 ноября, 14:58

Визуальная опора — скриншот владельца и существующая тёмная система v6; это refinement, не новый стиль. Общий nav/pressed-tab focus теперь использует единую непрерывную границу без второго внешнего контура. Keyboard focus сохранён, forced-colors получает системный outline внутри той же границы. Drawer использует ту же модель.

Экран пользователей:
- `UserToolbar` компонует существующие Field/Button: поиск, доступ, группы при наличии и один список порядка (включает направление); сброс фильтров доступен по необходимости. Экспорт перенесён в заголовок списка, массовое создание названо «Добавить списком».
- Имя и ID выровнены одним grid рядом с checkbox, selected row имеет тихий фон без новой рамки. Протокольные metadata badges нейтральные; accent оставлен основным действиям и выбору.
- Обобщённый `userAccess` показывает административный запрет, отсутствие разрешённых подключений, ограничения пакета и отсутствие данных отдельно. Это presentation, не изменение серверного enforcement. Сводка не называет доступ «онлайн».
- Короткие неизвестные показатели вместо повторяющихся длинных сообщений; технические сведения раскрываются в UserDataStatus. Ошибки применения/конечного пакета не скрыты. Расход в Б/КБ/МБ/ГБ, пакет виден и до первого замера; реальный ноль не подменяет неизвестный расход.
- Короткий список не показывает пустую пагинацию и disabled кнопки. При большем списке остаются25/50/100, выбор страниц и batch semantics. На mobile поля переносятся, touch targets и data-label представление сохраняются.
