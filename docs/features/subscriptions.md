# Feature: подписки и восстановление

## Цель

Стабильный `subscription ID`, привязанный к пользователю, а не к конкретной VPN-ноде. При смене входного VPS ссылка не создаётся заново, если работает сервис подписок и доступен клиенту.

## Требования

- Один пользователь, несколько endpoint profiles (каждый с собственным портом, security, server address).
- QR, share links, форматы для Happ/совместимых Xray-клиентов.
- Подписка содержит **только реально применённые и проверенные** конфигурации; last-good публикация при ошибке раскатки.
- Отдельные primary/backup HTTPS subscription URLs, выданные заранее. Нужна поддержка клиента; конкретные заголовки Happ верифицируются по актуальной документации и в тестах.
- IP TLS certificate, автообновление, строгая TLS-проверка.
- Смена токена и отзыв подписки, безопасные non-guessable tokens; не логировать plaintext URL.
- Версии публикации, status, last update, last request без излишнего tracking.

## Принципиальное ограничение IP-only

При замене VPN-входа меняется содержимое подписки, но при замене **сервиса подписок** старый URL с мёртвым IP теряется. Без домена, переносимого адреса или заранее известного backup URL невозможно сохранить этот URL магически.

## Приёмка

Пользователь заранее подключил Happ. После удаления входного VPS и публикации нового профиля действующий endpoint обновления отдаёт новый IP. Если основной subscription IP недоступен, резервный URL доступен только при настройке и поддержке клиентом такого fallback.
