## Уточнения семантики

- «В сети» = только наблюдаемое состояние. Не заменять отсутствие данных нулём. Разделять online клиента, health Xray, доступность VPN-маршрута и достижимость панели.
- «Лимит устройств» без доверенного клиента — best-effort: IP не устройство; HWID может быть подделан. Отдельный credentials на устройство помогает отзывать доступ, но не доказывает физическую уникальность.
- Глобальный трафик между автономными нодами без постоянной связи — неизбежная согласованность с задержкой. Пределы превышения и политика офлайн-режима документируются.
- Изменения firewall проверяются снаружи, не только по UFW status; правила облачного firewall могут отличаться.
- Подписки через IP: при замене VPN-входа обновляем содержимое, а при замене сервиса подписки нужен заранее известный резервный IP/URL.
- Для обычного пользователя «Inbound» называется «Подключение», технический термин остаётся в деталях.
