# Продуктовая концепция

Сделать удобную компактную систему управления VPN для собственного VPS, семьи и малых групп. Пользователь должен быстро перейти от чистого VPS к работающей подписке и при желании расширить инфраструктуру дополнительными серверами, каскадами и резервами.

## Основные сценарии

1. **Один VPS:** установить панель и Xray, создать пользователей, выдать ссылку Happ, видеть трафик и состояние системы. Никакой обязательной ноды.
2. **Несколько независимых VPS:** добавить сервер через SSH прямо из UI; пользователи выбирают нужный сервер через одну подписку.
3. **Каскад:** указать вход и выход в любом порядке (RU → NL, NL → RU и т.д.), проверить фактический egress, включить резервный выход.
4. **Отказ:** выходная нода недоступна → новые соединения переходят на резерв; входная недоступна → клиент использует заранее предоставленный альтернативный вход/обновлённую подписку, если клиент поддерживает.
5. **Замена VPS:** оператор вводит новый адрес/SSH-доступ; система восстанавливает логическую роль, пользователей, порты, маршруты и публикацию подписки.
6. **Администрирование:** безопасность VPS, пользователи, устройства, лимиты, логи, обновления и backup из интерфейса.

## Что делает продукт отличным от простого форка

Понятная модель «серверы, подключения, пользователи, маршруты»; безопасная автоматизация; простой и расширенный режимы; строгая диагностика; отсутствие необходимости вручную синхронизировать клиентов и редактировать JSON.

## Не обещать

- «Невидимый» VPN или гарантированное отсутствие блокировок.
- Мгновенное бесшовное восстановление TCP при переключении входного/выходного VPS.
- Строгое подтверждение физического устройства по IP/HWID.
- Сохранение URL подписки по IP после потери самого IP без резервного пути.
- Работу на 1 ГБ при любой нагрузке без измерений.

## Не входит в первоначальную область

Биллинг, публичный SaaS, мультиарендность, Kubernetes, свой VPN-протокол/криптография, хранение подробных персональных логов трафика по умолчанию.
