# 0.7.0 stage5: профили и диагностика target — локальный control plane

Дата: 2026-11-05. Это продолжение исходников, не production release/приёмка этапов 4–5. Тестовых VPS нет, пользователь разрешил продолжать локально.

Реализованы CRUD/импорт/экспорт неактивируемых профилей трафика, модель объяснения правил, CAS и backup v5. В UI простые списки и мобильный диалог отделены от лениво загружаемого графа каскадов. Исправлены stale response проверки формы и каноническая дедупликация списка/файла.

Добавлены кандидатный каталог SNI, ручной импорт, защищённая загрузка подписанного feed с независимым ключом/expiry/anti-replay и ограниченные per-node TCP/TLS/HTTP2 проверки через typed low-privilege агент. На новом основном VLESS рекомендация заполняет только пустой target, XHTTP имеет явный выбор пары; диагностика нод доступна со страницы серверов. Действующая конфигурация не меняется фоновыми пробами или импортом каталога. Нет автоматической миграции remote SNI или доказательства VPN.

План установки уточнён: одна проверенная команда, IP TLS 160 часов, домен по желанию, size/retention журналов. Установщик этим блоком не менялся. Пользовательский сценарий «параллельно проверить протоколы/серверы, после повторных неудач сменить протокол текущего сервера, затем сервер» описан отдельно; client runtime не реализован и не имитируется heartbeat панели.

Контракты: [профили/targets](features/traffic-profiles-and-targets.md), [ADR-005](adr/005-traffic-profiles-and-target-diagnostics.md), [client failover](features/client-auto-switching.md). Доказательства: [фактические Go/frontend/Chromium результаты](testing/local-results/stage5-2026-11-05-profiles-targets.md).

Ограничения: нет stage5 apply/ACK/egress/publish, клиентского auto-switch, Geo-runtime, VM/VPS acceptance и подтверждённого IP ACME renewal. Полный source ZIP передаётся с manifest; это исходники, не подписанный установочный релиз.
