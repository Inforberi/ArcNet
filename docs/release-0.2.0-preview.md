# ArcVPN 0.2.0-preview — отчёт о сдаче промежуточной сборки

**Дата:** 2026-11-04. **Назначение:** исключительно локальная и стендовая проверка, не production.

## Проверено автоматически

- `CGO_ENABLED=1 go test -count=1 ./...`: успешно, включая API/SQLite/backup/QR/logging/Xray config.
- `CGO_ENABLED=1 go test -race -count=1 ./...`: успешно.
- `CGO_ENABLED=1 go vet ./...`: успешно.
- `bash -n install.sh deploy/arcvpn-menu.sh`: успешно (только синтаксис).
- `node --check web/app.js`: успешно.
- `CGO_ENABLED=1 GOOS=linux GOARCH=amd64 go build`: успешно; бинарник приложен в `dist/`.
- Встроенный совместимый UI: Chromium, 1440/768/390/320 px; проверены вход, создание пользователя, ссылка, QR-диалог, экспорт, предпросмотр импорта, просмотр/изменение лимита логов. На основной странице не найден горизонтальный overflow; браузерных JS-ошибок нет. Из-за блокировки loopback внутри браузера запросы передавались тестовым мостом в реальный локальный Go API, а не через обычное браузерное соединение.
- SVG QR декодирован обратно в исходную строку при независимой проверке.

## Добавлено

1. Экспорт ссылок: прямой VLESS URI, Base64-текст, URL подписки, QR-код для URI и URL.
2. Экспорт и импорт **состояния ArcVPN** в зашифрованном файле: параметры локального VLESS/Reality, пользователи, идентификаторы и токены подписок. Перед импортом предпросмотр и подтверждение замены. Учётная запись администратора и действующие сессии не переносятся.
3. Сохранение токенов подписки при восстановлении; тест отката, если Xray не применил новую конфигурацию (эмуляция Xray).
4. Настраиваемая файловая ротация логов **только Go-панели**: 500 МиБ по умолчанию, диапазон 50–1024 МиБ; просмотр/очистка из интерфейса.
5. Мобильная навигация, улучшения поведения модальных окон.

## Известные ограничения

- **Нет:** независимых Go-нод, SSH-установщика нод, каскадов, автоматического резервирования, Hysteria2, WireGuard, AmneziaWG, глобального учёта трафика, лимита устройств/HWID, полного импорта из 3x-ui, двухфакторной аутентификации, управления портами UFW через UI.
- **Не ограничиваются** журналы Xray, `journald` и других сервисов. Лимит касается собственного файла логов панели.
- В архиве есть React/TypeScript/Vite исходники, **не проверенные сборкой**: npm registry был недоступен. Встроенный совместимый UI на HTML/CSS/JavaScript не является окончательным React-интерфейсом.
- Установка на реальный VPS, systemd, HTTPS на IP, работа Xray с VPN-клиентом, нагрузка 1 vCPU / 1 ГБ RAM, полный end-to-end failover — **не тестировались**.
- Установщик рассчитан на Debian/Ubuntu x86_64, нужен публичный IPv4, доступные порты и интернет для скачивания Xray и Certbot. Сценарий необходимо проверять на отдельной VM с консолью провайдера.
- Импорт заменяет текущие **VPN-состояние и пользователей ArcVPN**. Не импортирует штатную резервную копию 3x-ui. До восстановления необходимо сохранить собственную резервную копию.

## Решение о применении

Это инженерный preview для стенда. **Не ставить поверх действующей 3x-ui и не использовать как публичный VPN для личных данных**, пока не выполнены production-условия в `docs/implementation-status.md`.
