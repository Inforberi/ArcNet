# ADR-007: обновление мониторинга и композиция форм

2026-11-05. Решение для локальных исходников, без VPS/VPN acceptance.

Одна сохраняемая настройка cadence (5 секунд по умолчанию, варианты 5/10/15/30/60) живёт в существующей `settings`. Изменение и audit выполняются одной транзакцией. Collector читает настройку между циклами, UI-сохранение будит его сразу. SQLite history сохраняет прежний минутный bucket и двухчасовую retention; детализация истории не объявлена пятисекундной.

SSE передаёт только coalesced `refresh` с текущей частотой и timestamp. Клиент инвалидирует активные query keys и получает актуальную разрешённую проекцию через существующие API. Это не stream секретов и не полный snapshot fleet на каждое подключение. EventSource принадлежит авторизованному layout; обновляются только смонтированные данные. История перечитывается не чаще минуты. При ошибке stream остаётся ограниченный опрос с той же частотой, при скрытой вкладке подписка закрывается. Ни SSE reconnect, ни вкладка не запускают дополнительный collector.

Hub принадлежит `Server`: максимум 32 stream, один pending notification на подписчика, slow consumer не блокирует worker. У stream отдельный deadline каждой записи, обычный HTTP write timeout сохраняется для других endpoint. Сессия проверяется перед refresh и каждые 15 секунд keepalive; revoke закрывает stream. Нет URL-токенов или query-secret; cookie HttpOnly и same-origin boundary сохраняются. Worker закрывает stream при завершении. Проверка `systemctl is-active` кэшируется на пять секунд внутри `Server`, а не запускается для каждой карточки/вкладки.

Телеметрия агента отделена от apply/target checks и использует независимый последовательный lifecycle, bounded request и error backoff. Перед каждым отчётом атомарно перечитывается приватная credential: нет гонки с ротацией общей mutable Configuration. Optional header `X-ArcVPN-Telemetry: 2` запрашивает JSON cadence; старым агентам сервер оставляет ответ 204, старые контроллеры для нового агента сохраняют минутный fallback. Минимальный приём отчётов — 5 секунд; штатная частота агента следует ответу контроллера. Изменение частоты с 60 до 5 может ожидать ближайшего отчёта до минуты плюс задержка запроса. Heartbeat/probe/ACK этим не учащаются.

`ConnectionForms` владеет локальными draft и автозаполнением; `VPN` компонует формы и операции. `Advanced` — общий primitive дизайн-системы. API `/api/vpn/defaults` предлагает адрес только из сохранённой VPN-конфигурации или доверенного `--public-url`, никогда из входящего Host. Порты учитывают существующие enabled listeners и административный порт, но не объявляются проверенными OS bind. Генерация ключей/изменение служб остаются только в явном create/apply. Reality-кандидаты проверяются автоматически с bounded существующим API, TanStack Query дедуплицирует запросы. Ручные поля и отдельные drafts разных протоколов сохраняются при асинхронной рекомендации. Без подходящего target форма не выдаёт выдуманный успешный подбор.

Ограничения основного VLESS до дополнительных протоколов, учёт пользовательского пакета, устройства и каскадный runtime остаются отдельной незавершённой работой: [план](../planning/simple-operation-and-user-packages-2026-11-05.md).

Основания: React Query установлен 5.90.1, проверена близкая документация ветки [v5.90.3](https://github.com/TanStack/query/blob/v5.90.3/docs/reference/QueryClient.md); [SSE/EventSource](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events); [Go ResponseController](https://pkg.go.dev/net/http#ResponseController.SetWriteDeadline).

## Уточнение владельца 2026-11-08: UI polling

По прямому требованию собирать/обновлять polling современный UI больше не открывает EventSource. Один layout clock обновляет только активные queries после завершения предыдущего цикла; 5с default, прежняя настройка5/10/15/30/60 сохранена. Hidden/offline останавливают запросы. History/settings перечитываются раз в минуту. Старый серверный SSE endpoint остаётся для совместимости, его безопасность/лимиты не ослаблены. Пользовательская телеметрия получает batch RAM snapshot только текущей страницы/карточки без запуска движков на GET. [Контракт](../features/user-traffic.md). Базовый выбор отдельного коллектора и ограниченной истории сохранён.
