# ADR-003: подписки без обязательного собственного домена

**Статус:** проектное решение. **Дата:** 2026-11-03.

## Решение

Панель/подписки поддерживают HTTPS по публичному IP с доверенным сертификатом. Пользовательская subscription identity стабильна и отделена от физических IP VPN-нод. Сервисы подписок могут иметь резервные URL на других IP.

## Почему

Пользователь не хочет привязывать собственный домен, но хочет не переимпортировать подписку при замене VPN-входа. Конфигурация выдаёт актуальные адреса через независимый subscription endpoint.

## Ограничение

При потере **самого IP сервиса подписок** его старый URL не сможет оставаться действующим без независимого резервного пути. Резерв должен быть выдан клиенту заранее. DNS не обязателен, но без него нельзя автоматически переадресовать прежний IP URL на чужой новый IP.
