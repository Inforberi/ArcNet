# ADR-017: внешняя проверка каскада и отдельная публикация

2026-11-06. Продолжает ADR-015/016; клиентские UUID/порт/REALITY/подписочный token не меняются.

После ACK обоих узлов администратор скачивает из UI одноразовый credential bundle. Grant5мин хранится только hash и связан с deployment version и revision/digest обеих нод. File содержит существующую ссылку доступа и token отчёта; браузер не хранит его в Query/localStorage. Runner — независимый Linux host, доверенный Xray: `chmod 600 arcvpn-cascade-probe.json`, затем `arcvpn cascade-probe --controller https://PANEL --grant-file arcvpn-cascade-probe.json`. Origin подтверждается отдельно от файла, secrets не в argv, input no-follow0600/bounded. File после проверки удалить. Отсутствие активного доступа не подменяется созданием скрытого клиента.

Runner использует один authenticated SOCKS→VLESS client без freedom fallback. Verified TLS204 затем HTTPS IP echo и RFC1035 DoH wire query `example.com A` к1.1.1.1 проходят через тот же туннель. Endpoints фиксированы, redirect/proxy/direct fallback запрещены, body/time bounded; outer process до60с. DoH проверяет request ID/question/QR/rcode/answer/public A. Это **DoH roundtrip через маршрут**, не аттестация DNS-политики ОС клиента и не DNS leak-test произвольных приложений. Официальный формат: [Cloudflare wireformat](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-wireformat/).

Только доверенный независимый runner может сообщать результат. Bearer сам по себе не доказывает место запуска/выполнение: agent/root/runner в TCB. Controller сверяет single-use grant, обе текущие применённые ревизии, lifecycle state, ожидаемый public IP выхода B и DNS mode. Неправильный IP/нет DoH → probe_failed, не PASS. NAT/другой исходящий IP требуют разбора/будущего явного expected-egress контракта; не принимаются молча.

Успех → verified, не автоматическая публикация. Отдельное session+CSRF+CAS подтверждение публикует стабильный endpoint A в существующих подписках; клиентский профиль прежний. Proof30мин; выдача проверяет обе ревизии/digests/states/expiry при каждом чтении, без внешнего запроса. Rollback/attention/изменение/expiry перестают выдавать публикацию; уже выданный профиль физически не отзывается истечением metadata. Новая проверка снимает прежнюю publication до нового подтверждения.

Для защиты выходного dial используется fixed `freedom.targetStrategy=UseIP` и finalRules: block приватных/служебных CIDR после DNS resolution, затем allow. Helper принимает только этот фиксированный набор; старые legacy cascade configs без него не подходят для новой публикации. Xray проверяет формат до runtime apply; старый несовместимый helper/engine не считается принятым. [Pinned upstream](https://github.com/XTLS/Xray-core/blob/v26.10.31/infra/conf/freedom.go). Нового shell RPC/файловых override/сетевых запросов при GET нет.

Ограничения сохраняются: два managed TCP/REALITY узла, без резервов и distributed device/finite packages; mutation leases до полноценного remote reconcile. Browser/VPS/REALITY/systemd/DNS leakage приёмка не заявлена. A2 Release не обновлён. Остальной согласованный объём активен в [плане исполнения](../planning/remaining-runtime-execution-2026-11-06.md).
