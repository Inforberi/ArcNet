# ADR-005: профили трафика и отдельная диагностика REALITY target

Дата: 2026-11-05. Решение: принято для локального control plane. Внешняя приёмка отсутствует.

Профиль выбора трафика отделён от физической RoutePolicy. SQLite хранит нормализованные правила proxy/direct/block, порядок, DNS-намерение и enabled; CAS предотвращает потерю правок. `enabled` — свойство сохранённого намерения, не включение runtime. API не имеет publish/apply. Экспорт — собственный JSON ArcVPN, не заявленная совместимость Happ. Backup v5 включает профили и инвалидирует старые версии форм при восстановлении; v1–v4 сохраняют существующие профили.

Target/SNI-каталог содержит кандидатов, а не доверенные рекомендации. HTTPS-загрузка требует независимо установленный Ed25519 ключ, signature domain separation, срок годности и монотонный watermark версии источника; ручной импорт не сбрасывает watermark. Версия сохранённого каталога для CAS отделена от подписанной версии источника. Загрузка ограничена HTTPS:443, размером/временем, без redirect/env proxy/TLS bypass и с pin проверенного публичного IP после DNS.

SNI-проба — отдельный ограниченный read-only контракт агента v1: node ID, digest кандидатов, срок, lease/retry, bounded queue. Не root-helper и не shell RPC. Старый агент не объявляет поддержку и не получает задание; новый агент терпит 404 старого контроллера. Нормальный heartbeat wire format не изменён.

Три успешных TCP/TLS1.3+h2 соединения с проверкой сертификата и успешный HTTP/2 ответ без redirect дают только пригодность target по этим критериям. Выбор — минимум медианы TCP+TLS среди прошедших; локальная проверка не характеризует сеть клиента. Контроллер пересчитывает метрики, привязывает отчёт к ноде/заданию/времени и всегда сбрасывает VPNVerified. Скомпрометированный агент способен подделать наблюдения: отчёт не независимый VPN proof и не снимает gates публикации.

UI может заполнить **пустое** поле нового подключения рекомендацией и даёт явный ручной выбор. Действующие SNI не мигрируют автоматически. Каталог и диагностические задания не входят в перенос VPN-state v5; после переноса каталог импортируется заново, проверки выполняются с новых нод. Приватный ключ подписания feed остаётся у поставщика; панель получает только независимо установленный публичный ключ.

Отклонены: общий граф для правил и каскадов; ручной непроверенный target как «автоматически проверенный»; ICMP как доказательство VPN; импорт trust key из скачанного feed; копирование runtime статуса при restore; реализация клиентского failover на стороне панели.
