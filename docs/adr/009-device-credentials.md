# ADR-009: отдельные доступы устройств локального Xray

2026-11-05. Объём: локальные VLESS/REALITY TCP и XHTTP, без новых протоколов.

Каждый доступ имеет отдельные случайные UUID и subscription token. Это идентичность credential, не физическое устройство/HWID, не число IP и не ограничение одновременных сокетов. Скопированный ключ нельзя надёжно отличить от оригинала. По умолчанию существующие пользователи продолжают использовать общий доступ; первое добавление устройства после явного UI-предупреждения навсегда отключает общий credential и его экспорт. Новые пользователи не требуют начальной настройки. Имя первого устройства предзаполнено, лимит — в расширенных настройках.

Лимит 0 означает отсутствие тарифного ограничения; защитные границы — 100 активных / 500 исторических credentials пользователя, 10000 всего. Это программные границы объёма, не измеренная вместимость VPS. Отзыв необратим для данного ID, освобождает активный слот; новая выдача создаёт новые секреты. CAS и проверка лимита принадлежат транзакции SQLite, mutations сериализованы с apply/restore в App.

Изменение сохраняет desired policy даже при ошибке apply, статус явно pending/apply_failed. Существующий worker повторяет применение. Генератор разрешает только неотозванные устройства активного пользователя с действующим пакетом. При сбое службы прежний VPN может продолжаться до успешного apply; успешное сохранение не доказывает завершения соединений. Живой disconnect подтверждается отдельно на VPS.

Учёт суммирует все известные aliases устройства и прежнего общего credential в два существующих user counter streams. Даже отозванные aliases учитываются до смены epoch, поэтому отзыв не вычитает уже использованный трафик. Проверка UUID активной конфигурации и защита монотонности сохраняются. Счётчики/квота общие для пользователя; недоказанный per-device online/traffic не показывается.

Private DB содержит policy/credentials и индекс активных subscription tokens. Списочный API возвращает только ID/имя/даты, секреты — в отдельном авторизованном export endpoint. Mutations требуют session+CSRF; публичная подписка проверяет token, отзыв, активность родителя и пакет. Secrets не попадают в audit. Статический список активных unmanaged UDP-движков или зарегистрированные ноды блокируют переход; device policy блокирует включение таких движков и deploy нод. Нельзя оставлять обход лимита через общий ключ другого движка.

Зашифрованный backup v7 переносит credentials и отзывы. Архивы v1–v6 сохраняют устройства совпадающих user ID+UUID. Stale v7 не отменяет местный отзыв и не восстанавливает общий ключ; действующий местный лимит сохраняется, несовместимое объединение отклоняется транзакционно. Изменившаяся identity считается новым пользователем. Компенсация неудачного удаления восстанавливает credentials/учёт/устройства в одной транзакции.

Компенсация неудачного импорта отличается от обычного portable restore: она точно восстанавливает device state, снятый App до попытки применения. Иначе объединение сохранило бы новые credentials неудачного импорта. Этот путь не доступен через HTTP и не отменяет известные до импорта отзывы.

Remote credentials, Hysteria2/WG/AWG devices, аттестация физических устройств, клиентский failover и реальный каскад не реализуются этим решением. Нет новых зависимостей, agent RPC или shell-команд панели.
