# ADR-012: первый локальный протокол без обязательного REALITY TCP

2026-11-06. Объём: VLESS/REALITY TCP, XHTTP, Hysteria2 и WireGuard; remote nodes, каскады, Geo и AmneziaWG не расширяются.

## Решение

`store.LocalServer` — отдельная от listener модель адреса локального сервера. Она строится одной read-only SQL-проекцией из явно сохранённых `config` и `protocols`, включая отключённые профили. Адреса обязаны совпадать; ошибка БД и конфликт не превращаются в пустую установку. Отдельная таблица/миграция не нужна: существующие установки получают ту же identity без ротации ключей. После удаления всех профилей и пользователей адрес можно выбрать заново.

`OptionalReality` означает отсутствие TCP-профиля, а не отсутствующий сервер. Первое создание XHTTP/Hysteria2/WireGuard принимает явный IP; последующие подключения сохраняют этот IP. Настройка TCP после другого протокола проверяет совпадение адреса и конфликты портов до apply. Для последнего сохранённого профиля без TCP запрещено удаление при существующих пользователях: можно оставить его отключённым, добавить другой или сначала удалить пользователей. Это сохраняет identity и валидность backup.

Auxiliary-only установка не генерирует ключи/конфиг Xray и не требует его бинарника для создания профиля или пользователя. Единственный XHTTP создаёт только свой inbound. При переходе с существующего Xray конфигурация всё ещё обновляется, чтобы прежний inbound не остался активным. Прежние validate/apply/compensation и allowlisted root helpers сохраняются, arbitrary shell RPC не добавляется. Установщик/состав пакета этим блоком не меняются.

## Учёт и доступ

Свежесть требует отчётов только включённых источников: TCP/XHTTP → Xray, Hysteria2 → Hysteria, WG → WireGuard. Отсутствие Xray не блокирует измеренный расход auxiliary-only сервера; включение нового источника требует его отдельной свежести. Xray Statistics фильтрует потоки по фактическим inbound tags, без выдуманного TCP stream при XHTTP-only.

Пользователи, отдельные устройства, toggle/revoke и reconcile работают без TCP-профиля. URI подписка включает только включённые URI-протоколы. Для WG-only URI отсутствует: API возвращает пустые `link`/`links`, UI предлагает `.conf`, а прямой URI QR отклоняется с 409. Поле `link` выбирает первый доступный URI; старый `format=vless` QR остаётся совместимым alias для этого URI, подпись UI теперь общая. UUID/token/ключи существующих подключений не ротируются.

## Перенос и откат

Backup v10 явно разрешает `vpn:null` с независимыми профилями, пользователями, credentials/devices/usage; v1–v9 читаются по прежним ограничениям. Новый сценарий не маскируется под v9. Все профили должны иметь общий адрес, orphan credentials и коллизии по-прежнему запрещены. Перенос IP без TCP поддержан; Hysteria IP SNI меняется вместе с IP, прежний снимок не мутируется. Сертификат нового IP должен быть выпущен отдельно.

Restore применяет состояние без разыменования отсутствующего TCP-профиля. При ошибке восстанавливает БД и прежние движки даже у auxiliary-only сервера. Новых DB schema, публичных secrets, привилегированных RPC и зависимостей нет. Откат к старому core требует совместимого backup: v10 старым core не читается.
