**Статус на 2026-11-04:** `IMPLEMENTING / EXTERNAL_PENDING`. Отдельные Go-проверки пройдены согласно `docs/ai/current-task.md`; React production build не подтверждён. Этап **не закрыт**.

## A. Реализуем здесь (готовность к передаче на внешние проверки)

- [ ] `frontend/package-lock.json` зафиксирован; зависимости и версии воспроизводимы.
- [ ] `npm ci && npm run build` успешно выполняется на чистом окружении. Если здесь недоступен npm, оформлен воспроизводимый результат Codex/CI, **не ставить галочку заранее**.
- [ ] Все основные страницы (`Overview`, `Users`, `VPN`, `Nodes`, `Routing`, `Backup`, `Security`, `Events`) открываются через React Router без старого `web/` в production.
- [ ] Все кнопки и формы выполняют реальные разрешённые API-действия; пока серверные функции не готовы — они явно недоступны с объяснением, а не «успешны» в демонстрации.
- [ ] Проверены AuthGate, login/logout, истечение сессии, 401/403/5xx, invalid forms, loading/error/success, HTTP 204, повторные запросы.
- [ ] Проверены операции пользователей, QR/подписки, экспорт/импорт ArcVPN, сброс ошибок, навигация, состояние темы в cookie.
- [ ] Адаптивы 320/390/768/1024/1440, overflow таблиц/модальных окон, keyboard navigation, Escape/focus; скриншоты и зафиксированные ошибки.
- [x] Go содержит механизм `go:embed` React, не включает legacy fallback в production; `frontend-check` проверен на синтетическом bundle. **Реальная** сборка/браузерные переходы остаются непроверенными (см. отдельные пункты выше).
- [ ] Installer preflight проверяет SHA, порт/архитектуру и embedded React (`frontend-check` после установки runtime CGO библиотек). Реальная проверка на чистом VPS и схема полного rollback остаются внешним блокером.
- [ ] Тесты Go, TypeScript build, критические HTTP API tests и shell syntax проходят; результаты записаны.
- [x] `AGENTS.md`, индекс и статусы реализации обновлены для 0.3.3; неиспытанные функции явно помечены.

## B. Только внешняя среда (выполняет Codex или оператор по runbook)

- [ ] Чистая поддерживаемая Debian/Ubuntu VM: установка из release bundle одной командой, systemd running, правильные владельцы/права файлов, restart/reboot.
- [ ] HTTPS по публичному IP: доверенная цепочка, правильный SAN IP, повторный выпуск/renewal, без пропуска проверки сертификата.
- [ ] Реальный Xray: config test, запуск, VLESS + Reality handshake с отдельного клиентского устройства, egress через VPS.
- [ ] Firewall/SSH: нельзя потерять доступ; аварийный откат после ошибочного правила и конфликтов портов.
- [ ] React E2E по HTTPS (cookie auth, API, реальный flow, адаптивы); скриншоты и accessibility issues.
- [ ] Проверка rollback (нерабочая конфигурация не ломает последний рабочий VPN).
- [ ] Измерение CPU/RAM/объёма логов и сохранение протокола приёмки.

## Условие завершения

`LOCAL_PASS` ставится только когда **весь раздел A проверен** и расхождения исправлены. `ACCEPTED` ставится только при выполненных разделах A и B. Если внешний стенд недоступен, **этап 1 остаётся открытым**, но разрешается продолжать программирование других этапов с явно записанным риском; итоговый production ZIP не выдаётся.
