# ArcVPN 0.7.0-stage5: дашборд и восстановление доступа

2026-11-05. Статус блока: **DASHBOARD_RECOVERY_LOCAL_PASS**. Этапы 4–5 не приняты на VPS.

- Дашборд панели и зарегистрированных нод: реальные nullable CPU/RAM/swap/disk/network/sockets/uptime, история 120 минут, поиск, доступность и отдельные service/VPN/route состояния. Мобильный UI, две темы, график без новой зависимости.
- Ограниченные procfs-снимки, cache 5 секунд, worker 30 секунд, agent report около минуты, bounded SQLite history; background polling выключен для скрытой вкладки. Число пользователей через aggregate без чтения credentials. Параллелизм проверки пароля ограничен одним KDF с ответом 429 при занятости.
- Серверные команды просмотра безопасных настроек, сброса пароля и отзыва административных сессий. Активная 2FA сохраняется по умолчанию; удаление только явно. Пароль через stdin либо локальная генерация, без секрета в argv. Существующие VPN credentials сохраняются, операции транзакционны.

Контракты: [дашборд](features/dashboard-and-telemetry.md), [CLI](ops/local-admin-recovery.md), [ADR](adr/006-bounded-dashboard-and-local-recovery.md). Доказательства и ограничения: [результаты](testing/local-results/stage5-2026-11-05-dashboard-recovery.md).

## Не реализовано или не принято

GeoIP/GeoSite импорт/runtime, экспорт действующих клиентских правил и параллельный client failover, физический A→B/B→A и route publish не завершены. Одна команда установки, домен/продление и полная политика журналов требуют дальнейшей реализации/испытаний. Новые протоколы/stage6 не добавлялись.

512 МиБ / 1 vCPU — пользовательский контрольный профиль, не доказанный minimum для VPN. Docker/синтетические отчёты не подтверждают fleet, systemd, SSH, handshake, DPI-стойкость или реальные VPN throughput/egress. Старый wrapper на уже установленном сервере автоматически этим исходным изменением не обновляется.
